## The mission

Software built in Europe still runs on ground that isn't ours — owned elsewhere, governed elsewhere, answerable elsewhere.

We think that's the wrong default.

So we're making deployment in Europe so embarrassingly easy that choosing it becomes the obvious thing to do — not the principled one.

**Velve exists to change what "default" means.**
